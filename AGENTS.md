# Working rules

- All agents make and push code changes on the shared `feature` branch.
- Read the latest `feature` branch before editing and preserve other agents' changes. Do not force-push.
- Test changes before pushing.
- Do not merge into `main`, deploy, or trigger a production release unless the user explicitly says to publish.
- Keep changes small. Do not add speculative features, unnecessary abstractions, compatibility paths, or workarounds that conceal obsolete code.
